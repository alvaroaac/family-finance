# Glossary

## Household

The private workspace for the family. The MVP has one household: Casa.

## Lançado Por

The user who registered a transaction. For web entries, this comes from the authenticated user. For Telegram entries, this comes from the linked Telegram identity.

## Responsável

Optional person responsible for a transaction when the expense should not be treated only as a household expense. Default is the house.

## Conta Corrente

Operational account for everyday money movement.

## Conta Investimento

Account concept used to group savings and investment balances without modeling a full brokerage system in the MVP.

## Caixinha

Investment or savings bucket. MVP buckets are filhos, casa, and independencia financeira/aposentadoria.

## Transaction

Financial record for an expense, income, or future transfer-like adjustment. MVP focuses on expenses and basic income.

## Installment Group

The parent record for a parcelado card purchase. It preserves the original purchase context.

## Installment

One monthly parcel generated from an installment group.

## Category

Macro category for organizing transactions.

## Subcategory

Second-level category nested under a macro category.

## Categorization Memory

A learnable and explainable pattern that helps suggest categories in the future.

## Import Batch

One confirmed import operation, including source, counts, status, and metadata. It does not store the original raw file permanently.
