# Project Ideas

These ideas are intentionally outside the MVP. Keep this file as a backlog for future phases after the core product has real usage data.

## Dashboard And Analytics

- Category and subcategory charts.
- Month-over-month comparison.
- Year-to-date view.
- Spending trends by merchant.
- Projection of end-of-month spending.
- Alerts when the current month is trending above normal.
- Cashflow calendar.
- Review of recurring expenses and subscriptions.

## Budgeting

- Monthly budget by macro category.
- Flexible budget envelopes.
- Planned vs actual views.
- Budget rollover rules.
- Shared household targets.
- Alerts before overspending.

## WhatsApp

- WhatsApp bot after Telegram flow is validated.
- Text and audio entry.
- Confirmation and correction flows matching Telegram.
- Provider evaluation for WhatsApp Business API.

## Investments

- Detailed investment positions.
- Manual asset tracking.
- Broker import.
- Performance and contribution tracking.
- Asset allocation by goal.
- Retirement/financial independence projection.
- Emergency reserve target tracking.

## Banking And Reconciliation

- Additional bank importers.
- Credit card invoice reconciliation.
- Bank account reconciliation.
- Duplicate detection improvements.
- Recurring transaction detection.
- Transfers between accounts.

## Collaboration

- Multiple households.
- Invite flow.
- Roles and permissions.
- Expense settlement between responsible people.
- Comments or notes on transactions.

## AI Improvements

- Better merchant normalization.
- Embedding-based transaction similarity.
- Advanced categorization explanations.
- Automatic anomaly detection.
- Monthly financial summary generated in natural language.
- Suggested category cleanup based on real usage.

## Product Polish

- PWA install support.
- Offline-first transaction entry.
- Push notifications.
- Mobile shortcut for quick entry.
- Rich import error review.
- CSV export.
- Data backup and restore.
